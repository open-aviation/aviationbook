27  Aircraft information

Author

Xavier Olive

A number of flight information is usually not directly accessible from settings recording aircraft trajectories. Metadata usually refers to any additional information enriching a trajectory. Enriching trajectories with relevant information is usually a costly process, and access to such information can be complicated.

27.1 ICAO identifiers

The most common identifier for aircraft in radar-based technologies is the identifier of the transponder: a six-digit hexadecimal identifier, i.e. an integer written in its hexadecimal form, which classically identifies an aircraft uniquely. The surveillance background chapter explains how this identifier appears in Mode S and secondary surveillance radar; in the remaining of the book, it is commonly referred to as the ICAO identifier, or icao24 in data records (24 stands for the number of bits encoding the integer).

Ranges of addresses are reserved per countries, who are free to assign addresses to aircraft registered by their authorities. All US registered aircraft get an address in the 0xa00000 to 0xafffff range; in Europe, France gets 0x380000 to 0x3bffff, Germany gets next interval from 0x3c0000 to 0x3fffff, then the UK gets 0x400000 to 0x43ffff, etc.

optionalHyphenPattern = (pattern) => {
  let result = "";
  let inClass = false;
  for (const char of pattern) {
    if (char === "[") inClass = true;
    if (char === "]") inClass = false;
    result += char === "-" && !inClass ? "-?" : char;
  }
  return result;
}
matchesRegistrationPattern = (row, query) => {
  if (!query || !row.rawPattern) return false;
  const candidate = query.toUpperCase().replace(/\s+/g, "");
  try {
    return new RegExp(optionalHyphenPattern(row.rawPattern), "i").test(candidate);
  } catch {
    return false;
  }
}

WarningAre ICAO addresses unique?

Yes and no. In practice, for most short-term analyses, we can consider the answer is yes.

However, an aircraft may get a different transponder identifier when it gets a different registration. This may happen when the aircraft is sold to new owners who want to register their aircraft in a different country. Then, after the aircraft gets a new registration, its old identifier can be reassigned to new aircraft.

Also, most aircraft manufacturers keep a small set of transponders that they reuse across many newborn aircraft for test flights. Those usually correspond to temporary registration numbers.

To sum up, it is safer to keep in mind that:

  • the same aircraft can have different ICAO identifiers throughout their life;
  • the same identifier can refer to different aircraft depending on the day we get data from them.

27.2 Tail numbers

The tail number is the registration painted on the aircraft, roughly comparable to a licence plate. Registrations follow national conventions: F- for France, D- for Germany, G- for the United Kingdom, PH- for the Netherlands, and so on. Some prefixes also carry useful hints about categories or operators; for example, a national register may reserve sub-ranges for gliders, helicopters, state aircraft, test registrations, or particular airline fleets.

For a few countries, the relationship between the 24-bit ICAO address and the visible registration is algorithmic enough to be decoded directly. The best-known case is the United States. US registrations are N-numbers: N followed by one to five digits, optionally followed by one or two letters; the first digit is non-zero and the letters I and O are not used. The ICAO address range from 0xa00001 to 0xadf7c7 follows this sequence in a well-defined order, so addresses can be mapped directly to registrations such as N1, N1A, N1AA, and ultimately N99999.

Other countries are less uniform. Japan (JA) and South Korea (HL) have regular enough allocations for useful decoding rules. Some registers use numeric sequences, and others use stride-like patterns for three-letter suffixes, as seen for parts of the French, German, Canadian, Australian, and other allocations. These rules are best understood as practical reverse-engineered mappings: very useful for enriching data, but not a substitute for an authoritative aircraft register.

TipWhat is the PIA program?

To address privacy concerns, FAA has initiated the Privacy ICAO aircraft address (PIA) program to improve the privacy of the eligible US-registered aircraft, ADS-B equipped and flying in the domestic US airspace. Recent research [1] have shown this attempt is vain as it is very easy to break the anonymization and find which PIA address (between N41000 0xa4d691 and N42999 0xa4f946) is associated to which aircraft.

27.3 Aircraft type designators

DOC 8643 - Aircraft Type Designators by ICAO contains designators for aircraft types which are most commonly provided with air traffic service (ATS).

Each designator consists of a 4-letter code associated with a manufacturer and an aircraft type, e.g., A320 for Airbus A320, B78X for Boeing 787-10 or E190 for Embraer 190. More specific designators can be used for balloons BALL or gliders GLID.

This designator is often referred as typecode in aircraft databases and helps associating an aircraft type to an ICAO identifier.

27.4 Data sources

Maintaining a data base of transponder identifiers, aircraft tail numbers, type designators, owners and/or operators is a very cumbersome process. New aircraft are manufactured every month, which generates new transponder identifiers [2]. Some countries keep a database of their registered aircraft public (e.g. FAA (US), France, Switzerland or The Netherlands), but this is not a systematic practice in every country, and those do not always contain the transponder identifier.

There have also been some crowdsourcing effort to constitute and maintain aircraft databases based on various open records and entries on social networks. Such databases raise some privacy concerns among some aircraft owners, who may be tempted to vandalise those databases [3].

Some public aircraft databases:

  • The OpenSky Network aircraft database contains several hundreds of thousands of airframes;
  • Flightradar24 give access to an interface to search for individual aircraft;
  • The website www.airframes.org, but they are very strict about their terms of use;
  • Some Regional Monitoring Agencies (RMA) provide open access to data matching aircraft registered in their area, specifically in Europe or in the Middle-East.
